بسته PWA آزمایشی صندوق پرشیا جام

1) این فایل ZIP را در Cloudflare Pages و گزینه Upload your static files بارگذاری کنید.
2) فایل ZIP را انتخاب و Deploy کنید.
3) آدرس pages.dev را باز کنید و نمایش صفحه را بررسی کنید.
4) روی گوشی اندرویدی با Chrome صفحه را باز کنید و از منوی مرورگر گزینه Install app یا Add to Home screen را انتخاب کنید.

نکته مهم:
- آیکون فعلی یک نشان موقت PJ است؛ لوگوی اصلی در این نشست در دسترس نبود.
- این صفحه هیچ فرم ورود یا فیلد دریافت رمز ندارد.
- دکمه ورود مستقیماً به Web App آزمایشی Google Apps Script می‌رود.
- Service Worker فقط فایل‌های ثابت همین صفحه را کش می‌کند؛ داده‌های صندوق و صفحه ورود Apps Script را ذخیره نمی‌کند.
- این بسته فقط برای TEST است و به MAIN متصل نیست.
